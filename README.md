# my-cheque_configuration-addon-

this addon is used to print bank cheques in odoo through css code in the ui its content :
1- pdc payment
2- bank reference
3- cheque format 
4- cheque designs 

the main idea of this addon if a company wanna prints the cheque values what to do , now you have 4 pages first 
cheque designs where the user enters how and where  he wants the value of the print look like or placed , this page 
affect and override on the css styles in cheque format (where in the future it will only be for the devolopers only) 
which is related with the bank code then the user enters the bank reference page create record then enters the 
account.account model to add the exact bank code that he added hi styles to then the last step he enters the pdc payment
page , create a record then selects the payment type to send money , add amount , the partner name , the cheque date and 
last thing enables the display date , close date and close pay name checkboxes then print bank cheque and here you go a
pdf cheque is printed .
